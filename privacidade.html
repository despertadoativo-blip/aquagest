Política de privacidade — AquaGest Lite

Versão técnica inicial: 04/10/2026. Esta página deve ser revisada pelo responsável jurídico do projeto antes do uso comercial.

O AquaGest Lite funciona prioritariamente no dispositivo do produtor. O aplicativo não envia dados da piscicultura automaticamente para a equipe de desenvolvimento.

Dados tratados

O sistema pode armazenar localmente dados de acesso, piscicultura, viveiros, ciclos, biometria, alimentação, água, estoque, finanças, sanidade, relatórios e backups. O e-mail é usado para autenticação e recuperação de acesso.

Finalidade e isolamento

Os dados são usados para operar a gestão da piscicultura. Cada registro produtivo é vinculado à piscicultura atual. Backups exportados pela tela de Configurações são limitados ao usuário e à piscicultura autenticados.

Machine Learning

A contribuição para melhoria dos modelos é opcional e depende de uma ação explícita do produtor. O arquivo preparado para contribuição remove nomes, e-mails, localização, identificadores de usuário, piscicultura, viveiro e ciclo. O arquivo não é enviado automaticamente; o produtor decide se irá compartilhá-lo.

Retenção e direitos

Como o armazenamento principal é local, o produtor controla os arquivos de backup e deve mantê-los em local seguro. O produtor pode solicitar exportação, correção ou exclusão dos dados ao responsável pelo projeto, conforme a base legal e os procedimentos definidos pelo controlador.

Segurança e limitações

O aplicativo utiliza autenticação, PBKDF2, isolamento lógico por piscicultura, armazenamento persistente quando autorizado pelo navegador e backups validados. Nenhuma aplicação web local consegue impedir o acesso de alguém que controle o dispositivo, o perfil do navegador ou os arquivos de backup.
